# 秋招投递系统 · Jobhunt

以产品经理身份与 AI 协作搭建的两个自用工具，服务于秋招网申。

| 项目 | 是什么 | 许可证 |
| --- | --- | --- |
| [jobhunt-desk](./jobhunt-desk) | 本地求职看板：岗位清单、DDL 日历、投递台账与漏斗。Python 标准库，零依赖 | MIT |
| [jobhunt-filler](./jobhunt-filler) | Edge / Chrome 网申填表扩展：AI 只做字段映射，本地确定性写值，永不自动提交 | GPL-3.0 |

## 几个关键取舍

- **不做岗位爬取**：招聘平台有加密风控，绕过存在法律风险。岗位由我自己录入。
- **扩展只填表，不自动提交**：最后那一下永远由人点。
- **识别不准时宁可留空，不填错**：留空用户看得见，填错要靠核对才能发现。
- **不存储 HR 个人信息**。

## 结果

- 185 项单元/集成测试与 28 项端到端检查全部通过
- 同一批岗位对照：单次网申填写从 23 分钟降到 14 分钟

## 一个值得记下的教训

185 项单元测试全绿，但「标签带星号即必填」这条规则在真实网页上从未生效——上游的文本清洗在判断之前就把星号洗掉了。是在真实页面上跑端到端测试才发现的。AI 写的代码通过测试，只说明它满足了 AI 自己理解的规格；验收必须放在真实场景里。
